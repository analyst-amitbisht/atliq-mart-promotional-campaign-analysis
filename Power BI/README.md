# Power BI Dashboard – AtliQ Mart Promotional Campaigns

## Overview

This folder contains the Power BI dashboard developed to analyze the performance of AtliQ Mart's Diwali 2023 and Sankranti 2024 promotional campaigns.

The dashboard presents key sales metrics and promotional performance across campaigns, promotion types, product categories, individual products, and store locations through interactive visualizations.

Power BI was used to create interactive dashboards to explore sales performance, compare promotional strategies, and identify key business insights.
