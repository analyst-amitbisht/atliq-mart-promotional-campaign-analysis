# Python Data Preparation – AtliQ Mart Promotional Campaigns

## Overview

This folder contains Python scripts and notebooks used to prepare and validate the datasets for analyzing AtliQ Mart's Diwali 2023 and Sankranti 2024 promotional campaigns.

The work covers data loading, cleaning, transformation, and validation to ensure data consistency and readiness for further analysis.

All data preparation tasks were performed using Python and Pandas.
