# Project Documentation

## Overview

This folder contains the reference documents required to understand the business context, objectives, scope, and data structure of the AtliQ Mart Promotional Campaign Analysis project.

### Contents

| File | Description |
|---|---|
| Problem Statement | Outlines the business problem, project objectives, and key challenges to be addressed. |
| Business Requirements & Analysis Scope | Defines the business requirements, key analytical questions, and scope of the analysis. |
| Meta Data | Provides descriptions of the datasets, tables, columns, and their respective attributes. |

These documents serve as the foundation for understanding the project requirements and guiding the subsequent data preparation, analysis, and reporting activities.
